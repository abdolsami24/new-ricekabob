MADINAH MARKET — RESTYLE UPDATE (match madinah.boyscoding.com)
==============================================================
This package makes the site look like madinah.boyscoding.com
(cream + deep green + gold) and includes the Madinah Market
name change. Only the LOOK changes — ordering, kitchen board
and accounts work exactly as before.

FILES IN THIS PACKAGE (6):
  app/globals.css
  app/layout.tsx
  app/page.tsx
  app/track/page.tsx
  components/TopNav.tsx
  components/Storefront.tsx

HOW TO UPLOAD:
1. Extract this ZIP. Inside you will see ONLY two folders:
   app and components (plus this README). If you see more
   folders (supabase, lib, public...), it is the WRONG folder.
2. Go to github.com/abdolsami24/madinah-market
3. Add file -> Upload files
4. Drag in the two folders: app and components
5. Commit changes
6. Vercel rebuilds automatically (about 1 minute).
